Matched neighbourhood controls and label diagnostics for spatial encoders

This page describes the public repository PeterPonyu/tessera-st. The latest analysis code is in revision-r3/ at the tag 2026.11.17-revision-r3; the original release is in current-release/.

This leaf points to versioned code and archives. Public availability does not establish scientific clearance.

What the code does

It asks what a learned spatial encoder adds beyond averaging each observation with its neighbours, and how much the construction of a reference annotation decides that comparison before any method is run.

  • Label diagnostics from a reference annotation and its coordinates: chance-corrected homophily across scales, label informativeness, a label correlation length, and how well each observation's own expression predicts its label
  • Tuned neighbourhood-mean controls, selected on other patients with the same rule as each encoder's settings
  • Parameter-free propagation on each encoder's own graph, matched to its message-passing depth
  • Unmodified runs of GraphST and STAGATE through adapters, beside the Tessera-ST gated graph encoder
  • Component removals for all three encoders, including spatial positives without message passing

Tessera-ST is one evaluated encoder, not a validated superior architecture or a deployment-ready selector.
