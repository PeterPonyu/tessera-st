What the package does

Tessera-ST is Python code for spatial-domain detection in spatial transcriptomics. Graph encoders can smooth features over a spatial neighborhood graph; this package studies that mechanism by learning a per-edge gate that can stop smoothing at a predicted seam. The seam is an explicit output, not only an argmax over a smoothed embedding.

  • Adaptive edge gating (off: plain mean aggregation)
  • Multi-scale fusion (off: last layer only)
  • Boundary-contrastive loss (off: reconstruction only)
  • Calibrated uncertainty (off: raw softmax entropy)

Install and smoke

pip install -e ".[test,torch]"
pytest -q
tessera smoke-synth --epochs 150 --out experiments/synth_ablation.json

Real-section ablation needs a local labelled .h5ad and the real-data extra. See the repository README for command flags.
