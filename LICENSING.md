# Rights

Author-owned Tessera-ST code is released under the MIT licence in [LICENSE](LICENSE). Author-written text, tables and
result aggregates are released under CC BY 4.0.

This branch contains code, design notes and the project page. It contains no third-party measurements, annotations,
images, model weights or upstream method code. The archived analysis packages
([doi:10.5281/zenodo.24315838](https://doi.org/10.5281/zenodo.24315838) and the tagged versions of this repository)
contain inputs derived from public datasets. Each package records the source, licence, attribution and checksums of
the data it contains, and those data keep their original terms; neither preprocessing nor drawing a coordinate map
changes them.
