# Tessera-ST figure manifest

This manifest separates evidence already on disk from rendering and from genuinely new computation.
`experiments/*.json` files are generated, git-ignored artifacts; the release archive must carry every
artifact used for a reported claim. Re-rendering from an existing JSON is not new scientific compute.

## Main manuscript figures

### 1. Method profile (`fig:profile`)

- **A — Source:** `experiments/expanded_bench.json` (11 platforms, 3 seeds, core panel).
- **B — Builder:** `manuscript/make_figs.R` -> `manuscript/figs/fig_profile.tex`.
- **C — Claim:** Method--task fit is method-specific; no single rank profile dominates across contiguity.
- **D — New compute:** No. Re-render only from the existing JSON.

### 2. Complete benchmark heatmap (`fig:heatmap`)

- **A — Source:** `experiments/expanded_bench.json`.
- **B — Builder:** `manuscript/make_figs.R` -> `manuscript/figs/fig_heatmap.tex` plus `fig_heatmap_ras1.png`.
- **C — Claim:** Winner cells move across datasets; the core panel has no universal winner.
- **D — New compute:** No. Re-render only.

### 3. Synthetic spatial map (`fig:spatialmap`)

- **A — Source:** Deterministic synthetic tessellation parameters embedded in `manuscript/make_figs.R`.
- **B — Builder:** `manuscript/make_figs.R` -> `manuscript/figs/fig_spatialmap.tex` plus four raster tiles.
- **C — Claim:** Visual mechanism illustration for spatial contiguity, label scrambling, and prior behavior.
- **D — New compute:** No scientific compute. Deterministic figure regeneration only.

### 4. Predictive law (`fig:law`)

- **A — Source:** `experiments/expanded_bench.json` and `experiments/gtfree_proxy.json`.
- **B — Builder:** `manuscript/make_figs.R` -> `manuscript/figs/fig_law.tex`.
- **C — Claim:** GT contiguity tracks spatial-prior advantage; `coh_gain` recovers the direction label-free.

### 5. Confound controls (`fig:confound`)

### 6. Robustness panel (`fig:robust`)

### 7. Controlled causal mechanism (`fig:mech`)

### 8. Label-free proxy search (`fig:proxy`)

### 11. Component ablation (`fig:ablation`)

## Tables and scoped supplements

### 12. Per-dataset benchmark table (`tab:perdataset`)

- **A — Source:** `experiments/expanded_bench.json`.
- **B — Builder:** `manuscript/make_figs.R` -> `manuscript/figs/tab_perdataset.tex`.
- **C — Claim:** Reports the core 11-platform panel, dataset metadata, and best configurations without promoting one metric to ground truth.
- **D — New compute:** No. Re-render only.

### 13. Decoupled causal control (`tab:decouple`, v2 topic)

- **A — Source:** `experiments/mechanism_decoupled_v2.json`; human-readable audit in `experiments/mechanism_decoupled_v2_results.md`.
- **B — Builder:** Hand-typed table in `manuscript/paper.tex`, with every effect size, sign flip, and floor range derived and checked by `experiments/verify_manuscript.py`.
- **C — Claim:** On both substrates and both priors, contiguity has the larger normalized effect; only its arm flips sign and keeps the non-spatial floor flat. This strengthens only the controlled-manipulation leg.
- **D — New compute:** No. The adopted local JSON is required in the release archive. Rerunning the 400-epoch experiment would be heavy compute and is not required for packaging.

### 14. BayesSpace partial sensitivity candidate

- **A — Source:** `experiments/bayesspace_bench_partial.json` (8 available rows) and `experiments/bayesspace_bench.json` (2-platform summarized subset).
- **B — Builder:** No manuscript builder yet. Any supplement must be generated from the 8-row partial artifact with an explicit coverage column and failure/missingness note.
- **C — Claim:** At most: a scoped, incomplete sensitivity analysis over the eight completed platforms. It must not be described as the complete 11-platform panel or used to replace the core headline correlation.
- **D — New compute:** Packaging the existing eight rows requires no new compute. Completing all 11 platforms is new computation and requires explicit user authorization.

## Release checks

1. Run `python experiments/verify_manuscript.py` from the repository root.
2. Run `make -C manuscript clean pdf` and inspect page count, overfull boxes, and undefined references.
3. Build the draft archive with `python scripts/deposit_zenodo.py --build`; the builder fails if the adopted v2 script, JSON, result note, verifier, or this manifest is missing.
4. Do not publish the Zenodo deposition without the explicit irreversible-action confirmation.
